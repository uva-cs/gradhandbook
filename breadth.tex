\subsection{Breadth Areas}

\begin{enumerate}[nosep]
	\item Cyber Physical Systems, Internet of Things, Embedded Systems
	\item Machine Learning, Natural Language Processing, Information Retrieval, Text Mining, Data Mining
	\item Security, Privacy, Cryptography
	\item Theory and Algorithms
	\item Computer Systems
	\item Software Engineering
\end{enumerate}

\subsection{Courses in Each Area}

The official list is in the \href{\GRBC}{Graduate Record}.
However, that record is only updated annually. This documents changes between
updates to the graduate record.

A course may only be used to fulfill the requirement of at most one breadth area.
